# CIFAR-10 DP Failure: Lessons Learned

## Что произошло

Эксперименты BL-0 — BL-3 на CIFAR-10 прошли успешно:
- BL-0 (централизованное): 85.88%
- BL-1 (FedAvg IID): 86.73% ± 0.30%
- BL-2 (FedAvg α=0.5): 85.58% ± 0.12%
- BL-3 (FedAvg + Multi-Krum): 84.06% ± 0.15%

BL-4 (Central DP) провалился полностью: при любом разумном ε модель не обучается.

## Корневая причина: SNR несовместимость

### Формула SNR для DP-FL

```
SNR = n_active / (σ × √d)
```

Где:
- `n_active` — число клиентов в раунде
- `σ` — noise multiplier
- `d` — число параметров модели

Для обучения требуется SNR > 0.2.

### CIFAR-10 параметры

```
d = 290,000 (3-conv CNN)
n_active = 20
T = 200 раундов
δ = 1e-5
```

Noise multiplier σ для разных ε (sample_rate=1.0, 20 из 20 участвуют):

| ε | σ | SNR = 20/(σ×√290K) | Обучается? |
|---|---|---|---|
| 1 | ~57 | 0.00066 | НЕТ |
| 2 | ~28 | 0.0013 | НЕТ |
| 4 | ~14 | 0.0026 | НЕТ |
| 8 | ~9 | 0.004 | НЕТ |
| 20 | ~3.5 | 0.011 | НЕТ |
| 100 | ~1.1 | 0.034 | НЕТ |
| 1000 | ~0.3 | 0.12 | НЕТ |
| 10000 | ~0.08 | 0.46 | ЕЛЕ-ЕЛЕ |

Минимальный ε для SNR>0.2: примерно **ε > 5000** при n=20, d=290K.

### Откуда ε=8 в литературе

Литература использует ДРУ ДРУГИЕ условия:
1. **Per-sample DP** (cross-device FL): sample_rate = B/N ≈ 0.001 (batch из 32 из 50K данных). Сильная amplification → σ в 30× меньше.
2. **n >> 100** (cross-device): 1000+ клиентов активных → SNR в 7+ раз лучше.
3. **Малые модели** (d << 290K): ResNet-small на MNIST.

**Наш случай (cross-silo n=20)** — не тот режим, где ε=8 работает без компромиссов.

### Баг session 2: sample_rate=1/n как трюк

В сессии 2 был применён "фикс" sample_rate=1/n=0.05 вместо 1.0. Это физически неправильно: моделирует "20 активных из 400 клиентов" вместо "20 из 20". Дало σ≈0.83 для ε=1, SNR≈0.04 — по-прежнему не обучается, но это был ещё и неправильный расчёт.

## Фундаментальное ограничение

Для DP-FL необходима совместимость двух условий:

```
1. Обучение:  SNR = n_active / (σ × √d) > 0.2
2. ALIE-подавление: σ > √T × m_passed × z / √d ≈ 0.474 (для MNIST tiny)
```

При d=290K эти условия несовместимы при n=20.

## Решение: переход на MNIST + TinyMNIST

```
d = 9,000 (TinyMNIST)
n_clients = 100
clients_per_round = 20 (q = 0.2)
sample_rate = 0.2 (правильный расчёт!)
```

| ε | σ | SNR = 20/(σ×√9K) | ALIE suppressed (σ>0.474)? |
|---|---|---|---|
| 5 | 1.036 | 0.20 | ✓ |
| 10 | 0.755 | 0.28 | ✓ |
| 20 | 0.570 | 0.37 | ✓ |

Все три ε работают: обучаются И подавляют ALIE.

## Полученные уроки

1. **Всегда проверяй SNR** перед запуском DP-экспериментов: `n_active/(σ×√d) > 0.2`
2. **sample_rate = clients_per_round / n_clients**, не 1/n как трюк
3. **ε=8 в литературе** не значит "ε=8 всегда работает" — зависит от n, d, sample_rate
4. **n=100, q=0.2** — реалистичная cross-silo FL установка, дающая правильную DP amplification
5. **Малая модель + MNIST** — не ограничение, а соответствие методике; все тезисы сохраняются

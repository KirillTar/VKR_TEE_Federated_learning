# IDEF0 TO-BE — контекстная диаграмма A-0

Спецификация для построения в Ramus Educational (или draw.io, IDEF0 shape library).
Контекст: защищённый конвейер FedRoLA + центральная ДП + SGX-анклав.

**Цветовая схема (для показа разницы с AS-IS):**

- серый — элементы, уже присутствовавшие в AS-IS;
- зелёный (заливка / жирная обводка) — НОВЫЕ элементы TO-BE;
- пометка `[NEW]` перед названием стрелки / механизма в Ramus соответствует новому элементу.

## Единственный блок

**A-0: Защищённый цикл федеративного обучения модели**
(FedRoLA + адаптивный клиппинг + центральная ДП внутри SGX-анклава)

## Стрелки ICOM

**Входы (Input, слева):**

- I1: локальные обучающие выборки клиентов $\{D_1, \ldots, D_N\}$ *(AS-IS)*
- I2: начальные параметры модели $w_0$ *(AS-IS)*
- I3: гиперпараметры обучения ($E$, $B$, $T$, скорость обучения) *(AS-IS)*
- I4 **[NEW]**: параметры защиты $(\varepsilon, \delta)$ — целевой бюджет приватности
- I5 **[NEW]**: порог клиппинга на уровне примера $R$ (межорганизационный сценарий)
- I6 **[NEW]**: верхний потолок клиппинга клиентского обновления $S_{\max} = 2{,}0$
- I7 **[NEW]**: гиперпараметры FedRoLA (коэффициент мягкой фильтрации $\chi$, число слоёв в голосовании)

**Управление (Control, сверху):**

- C1: спецификация протокола агрегации *(AS-IS, но с изменением: FedAvg → FedRoLA)*
- C2: критерии остановки *(AS-IS)*
- C3: требования нормативных документов (152-ФЗ, приказ ФСТЭК № 21) *(AS-IS)*
- C4 **[NEW]**: спецификация адаптивного клиппинга и центральной ДП (правила, допустимые диапазоны $\sigma$, учёт бюджета через Rényi-DP)
- C5 **[NEW]**: политика аттестации анклава (перечень доверенных версий контейнера, ключи подписи, правила обработки отказа аттестации)

**Выходы (Output, справа):**

- O1: итоговые параметры модели $w_T$ *(AS-IS)*
- O2: метрики качества по раундам (ТОЗ, ТЗА в пилотных прогонах) *(AS-IS, расширено)*
- O3: журналы обучения (обезличенные агрегаты) *(AS-IS, расширено — без индивидуальных обновлений)*
- O4 **[NEW]**: квитанция удалённой аттестации (подтверждение исполнения в заявленной конфигурации)
- O5 **[NEW]**: метрики защиты (TPR/FPR робастного фильтра, фактически израсходованный бюджет приватности)

**Механизмы (Mechanism, снизу):**

- M1: клиенты *(AS-IS, расширено клиппингом на уровне примера через Opacus)*
- M2: сервер-агрегатор *(AS-IS, но теперь исполняется внутри анклава — см. M4)*
- M3: каналы связи *(AS-IS, дополнены взаимной аутентификацией на ключах аттестации)*
- M4 **[NEW]**: SGX-анклав под управлением платформы SCONE (доверенная среда исполнения)
- M5 **[NEW]**: служба удалённой аттестации

## Декомпозиция A0 — пять блоков цикла раунда t

Ниже указаны только изменения относительно AS-IS. Блоки, сохранённые без изменений, перечислены кратко.

- **A1. Инициализация раунда** *(AS-IS, + проверка аттестации клиентов)* — исполняется внутри анклава.
- **A2. Рассылка параметров** *(AS-IS, + подпись пакета ключом анклава)*.
- **A3. Локальное обучение на клиенте $k$** *(AS-IS, + опциональный per-sample клиппинг R через Opacus для межорганизационного сценария)*.
- **A4. Передача обновлений** *(AS-IS, + аутентифицированный канал к анклаву)*.
- **A5. Агрегация и обновление модели [NEW декомпозиция на A5.1–A5.3]** — исполняется внутри анклава:
  - **A5.1 [NEW]** Адаптивный клиппинг норм клиентских обновлений: $S = \min(\operatorname{median}\lVert\Delta_k\rVert, S_{\max})$, $\Delta_k^{clip} = \Delta_k \cdot \min(1, S/\lVert\Delta_k\rVert)$.
  - **A5.2 [NEW]** Робастная агрегация FedRoLA с мягкой фильтрацией: послойный косинусный анализ, голосование, перевзвешивание; обновление репутации $\alpha_k/\beta_k$.
  - **A5.3 [NEW]** Внесение шума центральной ДП: $\mathcal{N}(0, \sigma^2 \Sigma^2 I)$, чувствительность $\Sigma = R/(n \cdot |D_{\min}|)$ для уровня записей или $\Sigma = S/f_{\text{eff}}$ для уровня клиента.

## Заметки по построению в Ramus Educational

1. В свойствах каждой стрелки/механизма указать префикс `[NEW]` — это будет отображаться в отчёте и поможет ГЭК.
2. Для цветового выделения использовать Edit → Properties → Colors: заливка блоков A5.1, A5.2, A5.3 — светло-зелёная (#D9EAD3); обводка — #38761D, толщина 2. Новые стрелки — сплошные зелёные линии. AS-IS элементы оставить в стандартной чёрно-белой гамме.
3. При экспорте в PNG/SVG для вставки в Word — разрешение не ниже 200 dpi; фон белый.
4. Подписи на русском: имена блоков и стрелок формулировать как в таблице 2.1 главы 2 ВКР.

## Отличия от AS-IS (сводка одним списком)

- **Новые входы:** параметры защиты $(\varepsilon, \delta)$, $R$, $S_{\max}$, гиперпараметры FedRoLA — 4 позиции.
- **Новое управление:** спецификация ДП-конвейера, политика аттестации — 2 позиции.
- **Новые выходы:** квитанция аттестации, метрики защиты — 2 позиции.
- **Новые механизмы:** SGX-анклав (SCONE), служба аттестации — 2 позиции.
- **Декомпозиция A5:** вместо одного блока «Агрегация FedAvg» — три блока A5.1 (клиппинг) → A5.2 (FedRoLA) → A5.3 (шум ДП), строго в этом порядке, строго внутри анклава.

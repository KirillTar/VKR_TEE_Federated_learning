## Правила работы со списком (для всех последующих сессий)

1. Каждая новая ссылка в тексте ВКР → добавляется в этот файл **до** того, как номер появится в главе.
2. Номера **фиксированы**: если источник добавлен под номером [21], он остаётся [21] во всех главах. Не переставлять из-за новых добавлений.
3. При появлении дубля — использовать существующий номер, не плодить.
4. Оформление по ГОСТ Р 7.0.100-2018: авторы (до 4 — перечислять, 5+ — «первый и др.»), заглавие, тип, выходные данные, для электронных — URL + «дата обращения».
5. Нормативные источники — отдельным блоком с префиксом `Н`, при финальной сборке объединяются или остаются отдельными по решению научрука.
6. При сборке финального документа этот файл либо вставляется как отдельный `.md`-чаптер `99_references.md`, либо обрабатывается через pandoc `--citeproc` + `references.bib`. Пока — ручная нумерация.
